# AnimationPro

A Garmin Connect IQ application for creating and managing animations on Garmin devices.

## Features

- Animation creation and editing
- Customizable animation parameters
- Device-specific optimizations

## Requirements

- Garmin Connect IQ SDK
- Compatible Garmin device

## Building

1. Install the Garmin Connect IQ SDK
2. Open the project in Eclipse or VS Code with Connect IQ plugin
3. Build using the SDK tools

## Installation

1. Build the project to generate the .prg file
2. Use Garmin Express to install on your device
